## 五、跨页不一致清单（实现前需设计侧拍板）

1. **阴影漂移**：A2 定义 `0 8px 32px rgba(0,0,0,0.15)` /
   `0 4px 12px rgba(211,211,211,0.25)`；A3 实际用 `0.16` 与
   `0 4px 6px rgba(216,216,216,0.25)`。token 以 A2 为权威。
2. **红色描边分歧**：A4 标签 red `255,163,158` vs A6 提示框 error `255,204,199`
   （底色同为 `255,241,240`）。
3. **主橙双值**：`rgba(255,105,0,1)`（A3 个人中心图标 ×5）≠ `rgba(250,105,0,1)`（体系主橙）。
4. **A7 Small 禁用色**：Border/Link 用 `rgba(252,150,77,0.5)`，
   Medium/Large 用 `rgba(250,105,0,0.5)`；悬浮文字橙 `#FC964D` 亦独立于
   primary-hover `#E56000`（文字色 vs 底色 token）。
5. **圆角无 CSS 值**：档位齐全（A2），但组件与档位的对应关系仅在底图。

## 七、与 @repo/design-tokens 的映射

源 token 名 → 包内命名规则：`--color-*` → `--repo-ui-color-*`（序号保留）；
`$spacing-*`/`$width-*` → `--repo-ui-spacing-*`；`$shadow-N` → `--repo-ui-shadow-N`；
数值档位（圆角/高度/图标）→ 编号或语义命名。兼容别名层
（`--repo-ui-color-surface`、`--repo-ui-space-2` 等旧占位名）重定向至最近
设计规范值，映射关系逐条注释在各 foundation 文件内。

## 八、产品实现现状（2026-08 对既有产品仓库交叉验证）

既有产品仓库（pnpm monorepo，5 个 uniapp + agent/admin/adplatform）的
主题层与设计稿存在明显漂移，本仓库的 token 包已是权威值的更完整载体：

- **无集中 token 层**：产品仓库的 `packages/shared/design-tokens` 仍是
  模板占位值（6 个中性色），未被任何应用消费；实际主题分散在 4 套机制
  （Element Plus `:root` 覆盖 + 运行时 theme.ts、各 uniapp 的
  unocss.config.ts、uni.scss 默认值、adplatform Tailwind 默认）
- **主色三处漂移**：tablecard/user/namecard 的 `"xu-primary": "#FF7A27"`
  ≠ `#FA6900`；user 的 uni.scss 还残留 `#ff6b1b` / `#104f3c` / `#007aff`
- **状态色漂移/缺失**：success 落成 Bootstrap 绿 `#5cb85c`、warning 落成
  `#f0ad4e`、danger 用 EP 默认；hover `#E56000` / active `#F36600` /
  info `#0077FA` / 发丝线 `rgba(28,31,35,0.08)` 全仓零出现；
  secondary `#0B71F4` 仅 1 处页面硬编码
- **数值体系未落地**：无圆角/间距阶梯，无阴影 token（现存阴影为漂移值，
  如 `0 3px 4px rgba(152,130,113,0.4)`）
- **字体是唯一接近规范的层**：Poppins 全字重 @font-face +
  Roboto/PingFang SC 栈已就位（Inter 仅 adplatform）

若后续回写产品仓库，优先级建议：先修三处主色漂移与空语义槽
（`iu-success/warning/error: ""`），再以本 token 包为源统一四套机制。
